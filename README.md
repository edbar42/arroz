# arroz

Bootstrap script for a custom Arch Linux rice on top of Omarchy.

After this repository is pushed to GitHub, the workflow in `.github/workflows/deploy-pages.yml` publishes the installer to GitHub Pages at:

`https://edbar42.github.io/arroz/arroz.sh`

Run it on a fresh machine with:

```bash
curl -fsSL https://edbar42.github.io/arroz/arroz.sh | bash
```

You can also inspect the hosted script in a browser before running it:

`https://edbar42.github.io/arroz/arroz.sh`
